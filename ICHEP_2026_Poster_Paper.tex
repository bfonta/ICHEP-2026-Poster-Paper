\section{The NGT Scouting Stream at the HL-LHC}
\label{intro}

The CMS experiment at the LHC employs a two-tiered online selection system: the hardware-based Level-1 Trigger (L1T), operating within a \SI{12.5}{\micro\second} latency budget, and the software-based High-Level Trigger (HLT), with a \SI{1}{\second} latency allowance. Together, these systems reduce the \SI{40}{\mega\hertz} bunch-crossing rate to an affordable data-recording volume~\cite{cms}.
To circumvent computing and storage bottlenecks, CMS pioneered \textit{data scouting}, which reconstructs events at the HLT level and outputs a streamlined, analysis-ready format without retaining raw detector data for full offline reconstruction~\cite{scout}. \par

During the High-Luminosity LHC (HL-LHC) era, the instantaneous luminosity will reach \sm\SI{7.5e34}{\per\square\centi\meter\per\second}, resulting in an average pileup of 200 interactions per proton bunch-crossing and creating an unprecedentedly dense collision environment.
The Next-Generation Triggers (NGT) project~\cite{ngt} addresses this processing challenge through a novel NGT Scouting stream (Fig.~\ref{fig:concept}) designed to process and record \emph{all} L1T-accepted events at a rate of \SI{750}{\kilo\hertz} using a compact, \texttt{NanoAOD}-like format.
By comparison, the baseline HL-LHC scouting stream targets \SI{225}{\kilo\hertz}, whereas the standard HLT path records raw data at \sm\SI{15}{\kilo\hertz}~\cite{octdr}.
Achieving the target \SI{750}{\kilo\hertz} rate requires several key technical advances: offloading HLT algorithms to GPUs (targeting 50\% in Run~4 and 80\% in Run~5)~\cite{hlttdr}, defining a tailored lightweight data structure, establishing real-time calibration workflows building on Run~3 demonstrators~\cite{demonstrator}, and delivering offline-quality physics object reconstruction. \par

This work focuses on algorithmic advancements in HLT track reconstruction that allow NGT Scouting to approach offline-quality performance.
Section~\ref{sec:track} details these tracking improvements, Section~\ref{sec:perf} evaluates their computational and physics performance, and Section~\ref{sec:conclusions} presents our conclusions.

\section{Validation of Physics Objects}
\label{sec:valid}

Current validation tools present in the CMS collaboration are scattered, occasionally outdated, and often incomplete. On-going High-Luminosity LHC (HL-LHC) developments, including Next Generation Triggers (NGT) and High-Level Trigger (HLT) upgrades, demand a reliable and comprehensive validation of physics objects. We aim to provide detailed monitoring of these HL-LHC developments by enabling systematic comparisons across CMS software releases, data conditions, algorithm versions, and algorithm configurations or tunings. Our tools are fully integrated within the CMS software framework and are automated through its Data Quality Monitoring (DQM) service. Furthermore, due to structural similarities, we can frequently generalize these validation frameworks to offline physics objects.

To quantitatively evaluate physics object performance, four primary matching metrics are established:
\begin{itemize}
\item \textbf{Efficiency} measures the ratio of simulated objects matched to reconstructed ones over the total number of simulated objects.
\item \textbf{Fake Rate} quantifies the proportion of reconstructed objects that are not matched to any simulated object relative to the total number of reconstructed objects.
\item \textbf{Duplicate Rate} calculates the fraction of simulated objects that are matched to multiple reconstructed objects out of all simulated objects.
\item \textbf{Merge Rate} determines the fraction of reconstructed objects that encompass multiple simulated objects relative to the total reconstructed count.
\end{itemize}

\subsection{Object-Specific Frameworks}

At the High-Level Trigger, Particle Flow (PF) cluster validation provides a centralized tool that exploits hit-by-hit association logic between simulated truth and reconstructed information. Current efforts focus primarily on PF clusters in the Electromagnetic Calorimeter (ECAL) to compare the physics performance of several clustering algorithms designed for the High-Luminosity LHC. As an additional feature, custom ECAL event displays have been deployed to allow visual inspection of event topologies.

For secondary vertexing algorithms, a specialized performance evaluation suite has been developed. It incorporates a full set of simulated vertices including pile-up interactions, which provides a reliable fake rate estimation. The framework establishes a robust association to reconstructed vertices via tunable position and track-matching requirements based on existing track-to-simulated-particle associations via shared hits. This approach offers a flexible efficiency estimate that can be customized to different phase-spaces or decay types, making it essential for assessing the performance of current algorithms.

Jet validation serves as an indispensable tool to compare performance across different detector regions, jet algorithms, and hyperparameter configurations. The tool has already been exploited to improve physics performance by identifying hidden pitfalls in new algorithms. Validation for Missing Transverse Energy ($\text{MET}$) follows a similar methodology, with initial final results expected to be available soon.

In hadronic tau ($\tau_h$) validation, candidates are matched to generated visible taus using a spatial $\Delta R$ distance cut. The DeepTauID tau tagger effectively reduces fakes originating from jets, while fake mitigation from background leptons is currently being integrated into the HLT framework.

Finally, a new PixelTracks validation tool provides simulation truth for intermediate objects within the Patatrack pixel tracking algorithm. This allows an in-depth analysis of the reconstruction efficiency across all doublet, triplet, and N-tuplet seed cuts. This capability is especially relevant for Phase-2, where the number of Patatrack parameters grows into the hundreds, and the framework is also being leveraged to evaluate electron reconstruction.

\section{Conclusions}
\label{sec:conclusions}

We have developed essential validation tools tailored for monitoring Phase-2 detector and software upgrade efforts, which actively enable and motivate detailed performance studies and further algorithm developments. Work is currently ongoing to extend both the hadronic tau and MET validation frameworks. Looking forward, we plan to continue Particle Flow validation efforts by expanding to Hadronic Calorimeter (HCAL) clusters and eventually to full PF candidates. These ongoing and future efforts will benefit significantly from a comprehensive simulation graph currently under active development.
